# Sea Life (Havets dyr)

Fish, sharks, seals, whales and penguins for Minecraft, with fishing rods to catch them. A Bedrock add-on and a Java (Fabric) mod, in English and Danish.

**Website: https://ulfendk.github.io/minecraft-aquatic/** (på dansk: https://ulfendk.github.io/minecraft-aquatic/da/)

![The creatures](https://ulfendk.github.io/minecraft-aquatic/img/animals/orca.png)

## Features

- **35 creatures**: 19 fish (freshwater, sea and tropical), 3 sharks and a manta ray, 3 seals, 7 whales and 3 penguins.
- **Fishing**: the Angler’s Rod and the Sea Rod, with bites that depend on the biome, depth and time of day, and a fight with a tension bar. The vanilla rod catches some of the new fish too.
- **Tame a seal**, **ride a whale** by its fin, watch **penguins** toboggan across the ice.
- **Fish in buckets**, new **food** (smoked herring, fried plaice, stjerneskud, fish and chips…) and a **Fish Guide** that keeps your personal bests.
- Works with **Realistic Hunting**: fish and sharks can be spearfished. Seals, whales and penguins are protected.

## Install

- **Bedrock (Windows, Android, iOS)**: download `SeaLife.mcaddon` from the [latest release](https://github.com/ulfendk/minecraft-aquatic/releases/latest), open it, and turn on *Sea Life* under *Behavior Packs* in your world. Needs Bedrock 1.21.120 or newer. Servers: use the `.mcpack` files.
- **Java Edition**: put `SeaLife-fabric.jar` in your `mods` folder with [Fabric API](https://modrinth.com/mod/fabric-api) and [GeckoLib](https://modrinth.com/mod/geckolib) (Minecraft 26.3).

## Development

```sh
npm ci
npm run build      # build/behavior_pack, build/resource_pack and java/src/generated/resources
npm run validate   # static checks, including the Realistic Hunting hit models
npm test           # unit tests
npm run package    # dist/*.mcaddon, *.mcpack
npm run preview    # build/preview/sheet.png and one sheet per species
npm run site       # build/site (GitHub Pages)
npm run test:server  # Bedrock Dedicated Server smoke test (Docker)
cd java && ./gradlew build runGameTest
```

| Path | What |
| --- | --- |
| `src/animals/*.mjs` | One file per species: model, textures, animations, behaviour, spawning |
| `src/lib/` | Body plans, animation presets, texture painter, Bedrock entity generator |
| `src/fishing.mjs` | The catch table, rods and fight numbers (shared by both editions) |
| `src/items.mjs` | Fish, food, rods, buckets and recipes |
| `src/i18n.mjs`, `src/lang.mjs`, `src/guide.mjs` | Website and in-game texts in English and Danish |
| `src/packs/behavior_pack/scripts/` | Bedrock scripts: fishing, buckets, Fish Guide, behaviours |
| `tools/` | Build, validation, packaging, preview renderer, website, server test |
| `java/` | The Fabric mod; its resources are generated by `npm run build` |

### Adding a species

Add `src/animals/<id>.mjs` (see a similar species), an English guide text in `src/guide.mjs`, a Danish name and text in `src/i18n.mjs` and the `DA_EGG` form in `src/lang.mjs`. Fish also need a weight in `src/hunting.mjs`, and a catch table entry and item if they can be caught. Then run `npm run all` and `npm run preview <id>`.

## Releases

Bump `version` in `package.json`, add a section to `CHANGELOG.md`, then push a tag `vX.Y.Z`. The release workflow builds and tests everything and attaches the add-on, the packs and the Java jar.
